# Portfólio de Data Science e Python

Este repositório reúne projetos desenvolvidos durante minha formação em Data Science, com aplicações práticas de Python para análise de dados, modelagem estatística e aprendizado de máquina.

Os projetos exploram diferentes técnicas de análise e modelagem, passando por regressão, classificação e métodos de aprendizado não supervisionado.

## Projetos

### 1. Regressão Linear Múltipla

**Objetivo:** analisar a relação entre diferentes características de vinhos e sua avaliação de qualidade.

Neste projeto são explorados conceitos de regressão linear múltipla, análise exploratória dos dados, divisão entre dados de treinamento e teste, interpretação dos coeficientes e avaliação do desempenho do modelo.

**Principais técnicas:**
- Análise exploratória de dados
- Regressão Linear Múltipla
- Train/Test Split
- Análise de coeficientes
- R²
- MAE
- MSE
- RMSE
- Análise de resíduos

[Acessar projeto](./regressao_linear_multipla/)

---

### 2. Regressão Não Linear

**Objetivo:** analisar a relação entre o PIB per capita e o nível de felicidade dos países.

O projeto utiliza dados de 2016 e explora a aplicação de modelos de regressão não linear para representar relações que não são adequadamente descritas por uma relação linear simples.

**Principais técnicas:**
- Análise exploratória de dados
- Regressão não linear/polinomial
- Avaliação do modelo
- R²
- MAE
- MSE
- RMSE
- Análise de resíduos

[Acessar projeto](./regressao_nao_linear/)

---

### 3. Regressão Logística

**Objetivo:** aplicar um modelo de classificação utilizando o conjunto de dados Wine disponível no Scikit-learn.

O projeto aborda a construção e avaliação de um modelo de regressão logística, explorando a preparação dos dados, padronização das variáveis e diferentes métricas de classificação.

**Principais técnicas:**
- Regressão Logística
- StandardScaler
- Train/Test Split
- Probabilidades de classificação
- Accuracy
- Precision
- Recall
- F1-Score
- Matriz de Confusão
- Curva ROC
- AUC
- Interpretação dos coeficientes

[Acessar projeto](./regressao_logistica/)

---

### 4. Clusterização

**Objetivo:** identificar grupos de clientes com características semelhantes utilizando técnicas de aprendizado não supervisionado.

O projeto utiliza o algoritmo K-Means para segmentação dos clientes e explora diferentes métodos para avaliar a quantidade adequada de clusters.

**Principais técnicas:**
- K-Means
- Método do Cotovelo (Elbow Method)
- Silhouette Score
- PCA
- Análise dos clusters
- Visualização dos grupos

[Acessar projeto](./clusterização/)

---

### 5. Impacto do Gênero no Preço de Músicas

**Objetivo:** analisar a relação entre o gênero musical e o preço das faixas.

O projeto utiliza dados relacionados a músicas e gêneros musicais para investigar a influência do gênero no preço das faixas, aplicando técnicas de preparação dos dados e modelagem por regressão.

**Principais técnicas:**
- Análise exploratória de dados
- Tratamento e preparação dos dados
- Variáveis categóricas
- Variáveis dummy
- Regressão
- Interpretação dos resultados

[Acessar projeto](./impacto_genero_preco_musicas/)
